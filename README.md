## 🛠️ 如何「隨時更新」網站內容（免寫程式碼！）

我們在網站中直接內建了視覺化的 **【⚙️ 隨時更新管理工坊】**，您不需要修改任何 HTML 程式碼即可隨時增刪工具：

1. **步驟一：打開管理介面**
   * 用 Chrome 或 Edge 瀏覽器打開 `index.html`，點擊網頁右上角的 **「➕ 新增 AI 工具」** 或 **「⚙️ 隨時更新管理」** 按鈕。
2. **步驟二：在視覺化表單中編輯**
   * **新增／修改工具**：可自由設定工具名稱、所屬分類、多個應用連結（例如：教師主持端、學生作答端，還可勾選是否顯示課堂掃碼 QR 按鈕）、多個檔案下載網址（如 CSV 範本）、Step-by-Step 步驟、以及一鍵複製的 AI 提示詞（Prompt）。
   * **管理與擴充分類**：點擊「📂 管理分類」頁籤，除了原有的「👩‍🏫 教學與課程創新」、「🏛️ 校務行政賦能」等五大分類外，可隨時新增或調整分類。
   * **修改網站標題與簡介**：點擊「🏠 網站標題與校長簡介」頁籤，可隨時修改首頁金句與校長介紹。
3. **步驟三：一鍵永久存檔 (`tools-data.js`)**
   * 在管理視窗中點擊 **「💾 儲存更新 tools-data.js」**，在跳出的存檔視窗中選擇本資料夾內的 `tools-data.js` 並按下「儲存（覆蓋）」。
   * 儲存完成後，無論是您自己打開網頁，或是將這 4 個檔案上傳到 GitHub Pages（如 `kennycjh.github.io`），全世界進到網站的人都會立刻看到最新內容！
